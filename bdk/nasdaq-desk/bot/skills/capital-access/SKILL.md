# Capital Access knowledge capture

Nasdaq raised this use case: knowledge that lives inside people’s heads, not
only in Salesforce-style systems of record.

## Flow

1. Read the teammate interview notes (or pasted notes) from the grounded packet.
2. Draft a structured playbook: audience, process steps, decision gates, owners.
3. Stop for human approval. Until approved, refuse to treat the draft as live.
4. After approval, answer teammate questions using only the approved playbook
   and cite the source notes.
